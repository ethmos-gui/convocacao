# Convocação — site institucional

Site da [Convocação](https://convocacao.com.br/) — agência de comunicação e projetos missionais.

## Estrutura

- `index.html` — single-page com 8 seções (hero, sobre, serviço editorial, simulador teaser, portfólio editorial, comunicação, contato, footer)
- `img/` — imagens organizadas por seção
- `CNAME` — domínio custom `convocacao.com.br`

## Editar

Tudo é HTML+CSS inline. Sem build step. Edite, commit, push — Pages republica em ~1 min.

Para o simulador interativo, ver repo separado: [contemplatio-simulador](https://github.com/ethmos-gui/contemplatio-simulador).
